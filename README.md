# Artificial Technologies
This is a made up company that offers freemium servers.

This website was created for a class at [MSCS](https://www.southeastmn.edu/Index.aspx) and was created by Sam Swagger.

# Project Story:
This project originally started as a Business Plan for a technical writing class at Minnesota State College Southeast.
The professor advised to determine what the business would be before writing the business plan.
To get past writers block, I created this website defining the company's products, goals, target market, and color schemes.

I made the first "draft" of the website from scratch in three days, including writing every article, creating all graphics, and writing all HTML/CSS/JS.
I later came back and tested my JavaScript skills by adding a page that would allow the user to make files and webpages on this website.
It is deployed using [Microsoft Static Web Apps](https://azure.microsoft.com/en-us/products/app-service/static).

<small>There was no AI used to create any part of this website.</small>
